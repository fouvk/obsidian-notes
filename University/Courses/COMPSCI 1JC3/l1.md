## Push learning 
- learning what instructor/textbook tellls you to learn
- Important to learn at the beggining to be able to use pull learning
## Pull learning 
- learning what you need to solve/complete a problem or task (e.g. project)

This course is more orriented towards push learning, later will be more pull

## Passive learning
- done by absorbing information you see hear or read
- more accessible 
- ways
	- using ai to answer a question/write code
	- watch video/audio/lecture
	- read a textbook

mixed ways
- watch a video and take notes
- attend lecture take notes and ask question
- read a book take notes and do the exercises
## active learning
- done by discussing, analyzing, exploring information
- course focused on this
- need for a deeper and broader understanding
- **more painful
- ways
	- work on a challenging problem or do a project
	- discuss ideas with instructors/peers
	- prepare presentation or write papers
